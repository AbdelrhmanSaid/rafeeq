Rafeeq es una aplicación de acompañamiento para musulmanes diseñada para proporcionar recursos y herramientas útiles. Este repositorio contiene el código fuente de la aplicación.

## Características
- **Horarios de Oración**: Horarios de oración precisos basados en la ubicación.
- **Lectura del Corán**: Accede al Corán con traducciones y recitaciones.
- **Recursos Islámicos**: Una colección de conocimiento y herramientas islámicas.
- **Interfaz Intuitiva**: Diseño simple e intuitivo para facilitar su uso.

## Primeros pasos
### Requisitos previos
- [Bun.sh](https://bun.sh/) instalado en tu máquina.

### Instalación
1. Clona el repositorio:
   ```bash
   git clone https://github.com/AbdelrhmanSaid/rafeeq.git
   ```
2. Navega al directorio del proyecto:
   ```bash
   cd rafeeq
   ```
3. Instala las dependencias:
   ```bash
   bun install
   ```

### Ejecución de la aplicación
Para iniciar el servidor de desarrollo, ejecuta:
```bash
bun run dev
```
La aplicación estará disponible en `http://localhost:5173`.

## Analíticas
Para habilitar Google Analytics sin afectar el rendimiento ni la PWA, configura esta variable de entorno antes de compilar o ejecutar la aplicación:

```
VITE_GA_MEASUREMENT_ID=G-XXXXXXXXXX
```

Reemplaza `G-XXXXXXXXXX` con tu ID de medición de Google Analytics 4 obtenido en [Google Analytics](https://analytics.google.com/).
